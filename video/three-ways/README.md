## Что движется

| Время | Движение |
|---|---|
| 0–4 с | Хук слово за словом, каждое слово поднимается из своей маски. Три иконки падают сверху в ряд с разнесённым стартом и мягкой посадкой, под ними появляются подписи |
| 4–12 с | Полибэг выезжает в центр и увеличивается ×1,75, мятная линия шва «дышит». Заголовок набирается печатной машинкой с кареткой, чипы выезжают слева, строки ✓/✗ раскрываются слева направо. Трижды сверху опускается стрелка давления, и пакет проминается: сжатие по вертикали, скос, дрожание складок. Остальные иконки уменьшаются и уходят вниз |
| 12–20 с | Мейлер выходит на пружине с перелётом и затуханием, пузырьки надуваются по одному. «Drop test»: мейлер поднимается, падает на линию пола и пару раз мягко отскакивает |
| 20–27 с | Коробка фиксируется жёстко, без пружины (ease-out-expo, 0,45 с). Клапаны закрываются, мятная лента прорисовывается, щелчком встают угловые скобы. Пунктирный «рентген» формы внутри, медленный наезд камеры |
| 27–33 с | Все иконки возвращаются в ряд. **27,0–27,5 с — намеренная полная статика**: стоит даже фоновая сетка, приглушена музыка. Затем чип COSMETICS прилетает к полибэгу (иконка вздрагивает, ✗ REFUND REQUEST), чип BOOK — к коробке (✗ OVERPAY) |
| 33–36 с | Вопрос появляется словами с масштабированием. Светлый фон Bay Grey поднимается шторкой снизу, логотип заливается диагональю снизу-слева вверх-вправо: 600 мс, `cubic-bezier(.22,1,.36,1)`, без bounce, на экране 1,1 с |

Всё время фон — точечная сетка Dock Green, которая медленно дрейфует. Иконки вне фокуса слегка покачиваются, кроме коробки: она «жёсткая».

### Проверка движения (`check_motion.py`)

Скрипт считает разницу соседних кадров только по переднему плану (текст, иконки, субтитры), чтобы дрейф фона не прятал статику:

```
frames with foreground motion: 926/1079
longest foreground-static stretches:
   0.50 s   35.50 -> 36.00   (финальная выдержка логотипа)
   0.43 s   30.43 -> 30.87
   0.43 s   27.07 -> 27.50   (намеренная пауза)
any full-frame-identical stretch > 1 s: False
```

Ни одного отрезка дольше 0,5 с без движения переднего плана нет.

## Соответствие констрейнтам

- **Цвета:** только `#0B0D10`, `#4FDCA9`, `#0F5F4A`, `#F5F7F8` и белый. Второстепенный текст — белый с пониженной непрозрачностью, это не новый оттенок. Исключение одно — сам логотип: это оригинальный файл, и его градиент не перекрашивался (по правилу сайта логотип не перерисовывается).
- **Мятный акцент:** в тексте одно ключевое слово на сцену — *wrong*, *Useless for*, *Won’t survive*, *shape*, *category*, *actually*. В каждой иконке ровно один мятный элемент: шов полибэга, клапан мейлера, лента коробки.
- **Шрифты:** Manrope 800, Inter 600, IBM Plex Mono 500 подключены с Google Fonts CDN. Chromium в этой среде не проходит TLS через прокси, поэтому `render.mjs` перехватывает запросы к CDN и отдаёт их через curl. Страница при этом грузит те же URL, а рендер падает, если хоть один шрифт не загрузился.
- **Иконки:** сетка 64 единицы, линия 2 px, скруглённые стыки и концы. Без фото, людей и транспорта.
- **Субтитры:** английские, Inter 600 42 px. Белые на тёмном, Dock Ink на светлом, никогда не мятные. Нижний край — в 320 px от низа кадра (требование ≥ 240 px).
- **Аудио:** оригинальный синтез (`gen_music.py`) без вокала и сэмплов, поэтому лицензионных ограничений нет. Спокойный пэд и арпеджио, тихие акценты синхронно с анимацией, приглушение на паузе, −17 LUFS.
