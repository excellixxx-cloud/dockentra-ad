### Каких цифр на сайте НЕТ (и поэтому в ролике их нет)

- **Числового SLA / cut-off нет.** Страница `/sla` прямо говорит: «does not publish fixed numeric turnaround
  guarantees». Поэтому формулы вида «Our SLA: under 24h» в ролике нет. Единственные опубликованные
  обязательства — «same day» на приёмку/пересчёт и на фото; только они и использованы.
- **Цен нет.** Прайс приватный, присылают по WhatsApp или email.
- **Экономии для UK-брендов в цифрах нет.** Карточка «UK brands selling into Ireland» есть, но без цифр;
  в коде сказано, что €10 против €4,55 за посылку ждут перепроверки перед публикацией. Поэтому второй
  аргумент ролика — другой (см. ниже).
- Объёмов, числа клиентов, процента точности нет.

### Визуальная стилистика сайта → что взято в ролик

- **Цвета — с сайта, а не из брифа** (по правилу брифа «если отличается — бери с сайта»). В токенах сайта нет

  mint `#86e7ae` (только акценты на тёмном и уголки видоискателя), surface-soft `#f5f9f7`, white,
  muted `#5b6779`. Сторонних цветов нет. Mint не используется для текста на белом.
- **Шрифты совпадают с брифом:** Manrope 800 — заголовки, Inter — подписи, IBM Plex Mono — тайминги и метки.
- **Логотип** — оригинальный файл `dockentra-logo-transparent.png`, без изменений, только на светлом фоне
  (у него тёмно-синий вордмарк). Название — только «Dockentra».
- **Фото и видео на сайте** по решению владельца от 04.09 — временный иллюстративный материал, не склад Dockentra.

## 4. Музыка

Трек оригинальный: синтезирован кодом (`video/gen_music.py`), без сэмплов и чужих записей, поэтому
лицензионных ограничений нет. Спокойный пэд, мягкое арпеджио и суб-бас в ре мажоре, 96 BPM.
Арпеджио вступает вместе со сценой процесса (3,2 с). Прогрессия Dmaj9 → Bm7 → Gmaj7 → Em7 → Asus4 → A
разрешается в тонику ровно на CTA (24 с). На сменах сцен — очень тихий «воздушный» подъём, финал затухает.
Громкость выровнена до −17 LUFS, true peak −1,5 dBTP: тише типичной рекламы, голос платформы не перекрывает.

```bash
cd video

pip install numpy && python3 gen_music.py   # музыка -> out/music.wav
FFMPEG=$(python3 -c "import imageio_ffmpeg as i;print(i.get_ffmpeg_exe())") node render.mjs
node render.mjs --stills 2,8,13,22,28                                             # только PNG-кадры
```
